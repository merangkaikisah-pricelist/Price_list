# Merangkai Kisah - Price List & Portofolio Fotografi

Website katalog *Price List* dan *Portofolio* fotografi profesional **Merangkai Kisah**. Built with pure **HTML5, Vanilla CSS3, & JavaScript**.

---

## 🎨 Fitur Utama
- **Hero Section**: Tampilan beranda estetis *Dark Fine-Art* untuk menyambut pengunjung.
- **Price List Katalog**: Tab kategori (Lamaran, Prewedd, Wedding) yang menampilkan pilihan paket harga dan detail fasilitas lengkap.
- **Sekilas Cerita (Portofolio)**: Tampilan foto portofolio pernikahan dengan fitur *Lightbox Viewer* interaktif.
- **Direct WhatsApp Contact**: Tombol konsultasi dan tanya paket langsung terhubung ke aplikasi WhatsApp.
- **Responsive & Mobile-First Design**: Desain responsif yang optimal di tampilan HP (Mobile) maupun Desktop.

---

## 🚀 Cara Menjalankan
Website ini sepenuhnya bersifat **Static Website** (tanpa backend/database/PHP).

1. Buka folder projek di komputer Anda.
2. Klik 2x pada file `index.html` untuk membuka website langsung di browser favorit Anda.
3. Atau upload seluruh file di folder ini ke hosting gratisan seperti **GitHub Pages**, **Netlify**, **Vercel**, atau cPanel hosting mana saja.
